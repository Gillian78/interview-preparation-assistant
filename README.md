# Interview Preparation Assistant

本仓库为原Python面试准备助手的脱敏源码归档，供迁移到 Electron + React + TypeScript 的 Interview Float 使用。最终方向是单一桌面App；本仓库不代表新的独立产品部署。

## 阅读入口

- [MVP现状说明](MVP_CURRENT_STATE.md)：原始实现、调用链及已知缺口。
- [迁移分析](MIGRATION_SPEC.md)：迁移个人资料、JD分析、公司行业研究、领域知识包、知识收藏；不迁移模拟、评分、复盘、背诵、打卡。
- [发布清理说明](PUBLICATION_NOTES.md)：公开副本与本地原版的区别。

## 本地查看源码运行效果（可选）

Python 3.9+，仅使用标准库。在项目目录执行 `python3 app.py`，访问 `http://127.0.0.1:8765/`。也可执行 `sh start.sh`。服务绑定回环地址，不应直接公开到互联网。

资料、配置在运行后创建的 `data/` 中；此目录不提交。模型在页面API设置中配置，支持DeepSeek和豆包兼容接口。可选TTS变量参见 `.env.example`。浏览器语音识别支持情况取决于浏览器。

## 公开数据边界

不包含真实简历、个人经历、训练记录、考官截图、API Key、私有配置、原始个人题库或逐字稿。`questions.md`仅含通用示例，不能视为完整30题课程；因此旧JD模拟计划的题数也可能少于20题。背诵页面为公开占位说明。

保留原始功能代码用于审阅，不表示旧版所有功能已通过生产验收。目标仓库代码尚未纳入此归档。
